# 지방고용노동관서 · 산업재해조사표 접수 부서 연락처

사업장 주소를 넣으면 관할 지방고용노동관서와 산업재해조사표를 받는 부서(산재예방감독과 등)의
전화·팩스를 돌려준다. 확인일 2026-11-04(KST).

## 무엇이 들어 있나

| 파일 | 내용 |
|---|---|
| `jurisdiction.json` | 시도·시군구 → 관서. 근거 = 「고용노동부와 그 소속기관 직제 시행규칙」 별표 1(관할)·별표 1의2(중대재해수사과 관할)·별표 3(상위청) |
| `labor_offices.json` | 관서 49곳. 관서 주소·대표전화, 산재 관련 과 전부(공식 표기 그대로), 조사표 접수 과 표시(`accident_report`), 번호마다 확인 방법·출처 |
| `labor_offices.csv` | 위 JSON 의 부서 행을 표로 펼친 것(111행) |
| `find.mjs` | 주소 → 관서·접수 부서. 순수 함수 `findOffice(address, data, { construction })` |
| `find.test.mjs` | `node --test find.test.mjs` (15건) |
| `raw/` | 원자료 — 법령 XML·별표 텍스트(`law/`), 관서 화면 원본(`official/`), 젠스파크·마누스 결과(`genspark/`·`manus/`), 2025-09 전자팩스번호표(`keli/`), 점검 결과(`audit.md`) |
| `scripts/` | 다시 만들 때 쓰는 스크립트(아래 「갱신 방법」) |
| `prompts/` | 젠스파크·마누스에 보낸 지시문 |

직원 성명은 넣지 않았다. 부서와 번호만 있다(`scripts/audit.py` 3절 성명 누출 검사 0건).

## 쓰는 법

```js
import { findOffice, loadData } from './find.mjs';
const r = findOffice('서울특별시 강남구 테헤란로 152', loadData());
// r.status = confirmed | candidates | none
// r.office.report_to      → { dept, phone, fax, fax_status, address, source, ... }
// r.office.report_to_alt  → 지방청 직할 구역일 때 광역산재예방감독과(아래 「지방청」 참고)
```

명령줄 확인: `node scripts/demo_find.mjs "경기도 수원시 팔달구 ..." [--construction]`

- `construction: true` 면 건설산재예방감독과가 있는 관서(20곳)는 그 과를 돌려준다. 없는 관서는 산재예방감독과(팀)을 돌려주고 `construction_note` 를 붙인다.
- `candidates` 는 추정하지 않고 후보를 내는 경우다. 시도가 빠졌는데 같은 이름 시군구가 여러 곳(중구·고성군 등)이거나, 칠곡군 석적읍인데 리·산업단지 여부가 주소에 없을 때.
- 옛 이름도 받는다. 광주광역시·전라남도 → 전남광주통합특별시, 전라북도 → 전북특별자치도, 강원도 → 강원특별자치도, 경상북도 군위군 → 대구광역시 군위군, 인천 중구·동구 → 제물포구, 인천 서구 → 서해구(검단구 신설분 포함), 남구 → 미추홀구.
- 「광주시」는 뒤에 동구·서구·남구·북구·광산구가 오면 전남광주통합특별시, 아니면 경기도 광주시로 본다.

## 관할 근거 (법령)

- 법령: 고용노동부와 그 소속기관 직제 시행규칙(법령ID 006928, 법령키 0069282026082800482, 공포·시행 2026-08-28 판에서 받음)
- 별표 1 <개정 2026. 6. 30.> — 부칙 제472호 제1조 단서로 2026-07-01 시행
- 관서 = 지방청 7(서울·경기·중부·부산·대구·광주·대전) + 지청 41 + 출장소 1(영월) = **49**. 작업 지시의 「6개 청」과 달리 경기지방고용노동청이 별도 청이다
- 시도 경계를 넘는 관할: 철원군 → 의정부지청, 가평군 → 강원지청, 세종·공주·논산·계룡·금산 → 대전청, 경산·영천·청도 → 대구청
- 읍·리 단위 예외: 경북 칠곡군 석적읍 중리 구미국가산업단지 → 구미지청, 그 밖의 칠곡군 → 대구서부지청
- 제주: 법령상 광주청 관할. 조사표 연락처는 광주청 소속 **제주산재예방감독팀**(064-728-7155 / 팩스 0503-8803-1096, 제주시 청사로 59 정부제주지방합동청사)으로 바꿔 돌려준다(`jurisdiction.json` `contact_overrides`)
- 시도별 시군구 수 점검: `python3 scripts/check_jurisdiction.py` → 불일치 0

## 연락처 근거와 확인 방법

1순위 = 각 관서 홈페이지 부서 안내 화면 `moel.go.kr/local/{관서id}/introduce/dept/view.do`(부서코드별)의 「대표전화」·「팩스」 칸과 업무분장. 칸을 옮겨 채우지 않았다. 별관 부서 번호는 「찾아오시는 길」 별관 탭(`direction/list.do?gubun=3`)에서 읽었다.

`fax_status`·`phone_verification` 값:

| 값 | 뜻 |
|---|---|
| 공식 직접 확인 | 관서 부서 화면을 스크립트로 직접 받아 읽은 값(`raw/official/{id}/`) |
| 두 리서치 일치 | 공식 화면에 없고 젠스파크·마누스가 같은 값을 냄 |
| 단일 출처 | 출처가 하나뿐 |
| 미확인 | 값을 찾지 못함. 지어내지 않고 이렇게 적는다 |

### 결과 — 조사표 접수 부서(일반)

- 팩스: 공식 직접 확인 **48** / 두 리서치 일치 0 / 미확인 0 / 단일 출처 **1**(여수 — 작업 지시에 없던 구분이다. 미확인으로 바꿔 셀 수 있다)
- 접수 과: 지청 41 + 영월출장소 = 42곳 확정, 지방청 7곳은 미확정(아래 「미확인·주의 목록」)
- 전화: 공식 직접 확인 **49**
- 건설산재예방감독과 20곳: 전화·팩스 모두 공식 직접 확인
- 제주산재예방감독팀: 공식 직접 확인
- 젠스파크·마누스 대조: 부서 행 111개 중 팩스 103행이 세 출처 모두 같음. 나머지 8행은 두 리서치가 팩스를 비웠다. 그중 6행은 화면 팩스 칸도 비어 있고(중대재해수사과 5곳·광주청 광역과) 조사표 부서가 아니다. 부산북부는 업무분장 본문에서, 여수는 2025-09 전자팩스표에서 채웠다. 전화 3행 「다름」은 리서치가 빈칸이고 우리가 업무분장·별관 탭에서 찾은 경우(강원 중대재해수사과, 영월, 부산북부)
- 사람이 다시 연 표본 15건(수집 스크립트와 다른 경로, GET 으로 새로 열기): 15건 일치(영월은 전화만 다시 읽음) → `raw/official/manual_check.json`

### 칸 밀림(전화↔팩스 뒤바뀜) 검사 — `scripts/audit.py`

- 같은 부서 전화 = 팩스 0건, 전화 칸에 0503 번호 0건, 팩스가 다른 부서·대표 전화와 같음 0건, 공식 팩스 = 리서치 전화 0건
- 같은 관서 두 과가 전화·팩스를 함께 쓰는 곳 2건 — 부산청 광역과·산재예방감독과, 진주지청 중대재해수사과·산재예방감독과(화면에 그렇게 게시됨)
- 부서 전화가 관서 대표번호와 같은 곳 10건(직통이 아님) — 경기 건설과, 서울강남, 울산동부, 양산 중대재해, 포항, 목포 2과, 천안 3과

## 미확인·주의 목록

- **여수지청 산재예방감독과 팩스 = 단일 출처.** 부서 화면 팩스 칸이 비어 있다. 2026-02-13 공지로 과가 여수시 신월로 108(7층)로 옮기며 기계팩스 061-650-0230 사용을 멈췄다. 0503-8803-0638 은 2025-09 전자팩스번호표 값이다. 보내기 전 061-650-0136 으로 확인
- **관서 대표팩스**: 45곳이 공개하지 않는다(게시 4곳 = 서울강남·의정부·포항·안동). `main_fax` 가 null 이면 미확인이다
- **지방청 7곳의 조사표 접수 과는 미확정이다(결정 필요).** 지방청에는 광역산재예방감독과와 산재예방감독과가 따로 있다(2025-12-30 신설·개편).
  - 법령: 직제 시행규칙 제14조제13항제6호는 「사업장의 재해발생 상황파악, 원인조사 및 조치」를 **광역산재예방감독과장** 분장으로 둔다. 같은 조 제15항(산재예방감독과장)에는 이 항목이 없다. 대구청 화면도 이 항목을 광역과에만 적는다
  - 정황: 2025-09 전자팩스번호표(개편 전)의 「산재예방지도과」 팩스가 지금 **산재예방감독과** 팩스와 같다(서울·경기·중부·대구·광주 5곳). 팩스 회선을 이어받은 쪽을 보여 줄 뿐 업무가 어느 과로 갔는지는 말해 주지 않는다. 부산청 행은 팩스함 이름이 「광역산업안전감독팀」이다
  - 지금 데이터: `report_to` = 산재예방감독과, `report_to_alt` = 광역산재예방감독과. 두 번호를 함께 주고 `report_to.notes` 에 「미확정」을 적었다. 제출 전 전화 확인. 광주청 광역과는 화면에 전화·팩스가 없다
  - 해당 구역(법령 별표 1): 서울청(중구·종로·서초·동대문), 경기청(수원·용인·화성), 중부청(인천 제물포·미추홀·남동·연수·영종·옹진), 부산청(중구·동구·서구·사하·영도·남구·부산진·연제), 대구청 직할(경산·영천·청도 포함), 광주청 직할(광주 5개 구와 전남 8개 시군, 제주는 제주팀), 대전청(대전·세종·공주·논산·계룡·금산)
- **0503 전자팩스와 지역번호 팩스가 다른 곳 10건**: 부산청(일반·건설), 대전청, 서울서부, 서울북부, 부산동부, 창원, 진주, 대구서부, 익산. 화면은 지역번호 기계팩스, 2025-09 표는 0503 전자팩스다. `fax` 는 화면 값, 2025 표 값은 `efax_list_2025` 에 남겼다
- **서울남부지청**: 화면 팩스 02-6915-4346. 같은 관서 자료실의 2017-08-31 「산업재해조사표」 게시물은 02-2639-2279 를 안내한다(마누스가 찾음). 화면 값을 썼다
- **부산북부지청 산재예방감독과**: 화면 전화·팩스 칸이 비어 있고 업무분장 안에 「☎051-309-1556 FAX) 0503-8803-0416」이 있다. 그 값을 넣었다(출처 = 업무분장, `phone_source`·`fax_source` 에 적음)
- **서울강남지청**: 전화 칸이 「민원상담 02-584-0009」(대표번호). 업무분장 끝 TEL 02-3465-8498, FAX 02-598-4949 는 `phone_alt`·`fax_alt`
- **전주·군산·서산**: 팩스 칸에 번호가 둘. 앞 번호를 `fax`, 전부를 `fax_all` 에 둔다. 국번이 빠진 번호(전주 245-3461)는 `fax_raw` 에만 남긴다
- **부서 위치**: 별관·다른 건물에 있는 과는 `report_to.address` 에 따로 적었다(서울청 씨티센터타워, 서울서부 근신빌딩 별관, 목포지청 산재예방감독과 = 영암군 삼호읍 전남테크노파크 등). 비어 있으면 관서 주소를 본다

## 법령 관할과 관서 화면이 어긋난 곳

관서 화면의 관할구역 문구를 법령 별표 1과 대조했다(`raw/audit.md` 4절). 데이터는 법령을 따른다.

- 목포지청: 화면에 진도군이 없다. 법령은 진도군 포함
- 중부청·인천북부지청: 화면이 옛 구 이름(중구·동구·서구). 법령은 제물포구·영종구·서해구·검단구
- 광주청: 화면에 제주가 없다(제주는 제주산재예방감독팀 화면에 있음)
- 대전청(세종 표기), 대구서부·구미(칠곡 산업단지 문구)는 표현만 다르고 내용은 같다
- 젠스파크·마누스는 관할을 따로 조사하지 않았다(번호 조사만). 관할 판단은 법령만 쓴다

## 갱신 방법

`labor-office-directory/` 에서 차례로 실행한다. Windows 는 `PYTHONIOENCODING=utf-8`.

1. 법령: `curl -o raw/law/rule.xml "http://www.law.go.kr/DRF/lawService.do?OC=<법제처 OC>&target=law&ID=006928&type=XML"`
   → `python3 scripts/extract_annex.py raw/law/rule.xml raw/law` (별표 텍스트) · 조문은 `python3 scripts/dump_law_text.py raw/law/rule.xml <출력.txt>`
   별표 1 머리의 「<개정 …>」이 바뀌었으면 `build_jurisdiction.py` 의 별칭(`SIDO_ALIASES`·`SIGUNGU_ALIASES`·`SIDO_MOVES`)과 예외를 먼저 본다
2. `python3 scripts/build_jurisdiction.py && python3 scripts/check_jurisdiction.py` → 불일치 0
3. 관서 화면: `python3 scripts/collect_official.py && python3 scripts/collect_annex.py` → `raw/official/`
4. 전자팩스표(새 판이 나왔을 때만): `python3 -P -E scripts/parse_efax.py <xlsx> raw/keli/moel_efax_list_2025-09.csv | python3 ~/.claude/scripts/pii_gate.py`
   2025-09 판 출처 = 한국노동연구원(keli.kr) 게시 첨부 「1. 고용노동부 부서별 전자팩스번호.xlsx」
5. `python3 scripts/build_offices.py` → `labor_offices.json`·`.csv`
6. `python3 scripts/audit.py --md raw/audit.md` → 1절 칸 밀림 0건인지, 2절 비율, 4절 어긋남을 본다
7. `node --test find.test.mjs`
