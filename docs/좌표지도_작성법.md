# 좌표 지도(forms/maps/<FORM_ID>.json) 작성법

정본 예 = `forms/maps/F_YOYANG_APPLY.json`(요양급여신청서 1쪽 35칸). 이것과 같은 꼴로 만든다.

> 261026 밤 4팀 병렬 작성에서 확인된 것(12종 전부 적용됨):
> - `green_boxes` 는 **그대로 복사하면 안 된다.** 이웃 테두리·「년/월」 라벨과 합쳐지거나(폭 17~26), 붉은 테두리 상자는 아예 빠진다. 숫자 상자는 **그 y 띠의 `hlines` 조각 x0·x1(또는 `vlines` 쌍)** 으로 잡는다.
> - 체크 x 는 `[`.x1 과 `]`.x0 의 **중점**. 괄호 글리프 폭이 2~5pt 로 제각각이라 x0+6 은 틀린다. 전각 `〔 〕`·`□` 는 words/rawdict 글자 bbox 중심.
> - `accident_datetime` 은 12자리(YYYYMMDDhhmm)로 통일하고, 상자가 8·10개인 서식은 overlay 가 앞자리만 잘라 넣는다.
> - verify_fill.py 의 픽셀 문턱은 글자 수 비례(최소 +8)다. 홑숫자 「1」 때문에 샘플을 두 자리로 바꾸던 일은 이제 없어도 된다.
> - 스크래치 스크립트는 접두를 붙여 다른 팀과 겹치지 않게 한다.

## 좌표계
- 단위 pt, 원점 **쪽 왼쪽 위**(PyMuPDF). pdf-lib 는 왼쪽 아래 원점이지만 `src/fill/overlay.ts` 가 뒤집으므로 지도에는 PyMuPDF 좌표를 그대로 쓴다.
- `page` 는 1부터.

## 칸(slot) 종류
| kind | 필드 | 쓰는 곳 | 요령 |
|---|---|---|---|
| `text` | `x`(글자 왼쪽) `y`(**기준선**) `size` `maxWidth` | 보통 칸 | x = 셀 왼쪽 세로선 + 4~6. y = 셀 아래 가로선 − 4 (한 줄 셀) 또는 라벨 bbox 의 y1 과 맞춤. maxWidth = 셀 오른쪽 세로선 − x − 4. 넘치면 자동 축소되는데 축소는 시험에서 실패로 본다(`shrunk` 0) |
| `boxes` | `boxes:[{x0,y0,x1,y1}]` `size` | 녹색 한 글자 상자(주민번호·날짜·관리번호) | `probe` 의 `green_boxes` 를 **왼쪽→오른쪽 순서로 그대로** 복사. 사이의 하이픈·좁은 칸(폭 < 8)은 뺀다 |
| `check` | `x` `y`(괄호 중심) | `[ ]` 체크 | `probe` 의 `brackets` 에서 그 `[` 의 (x0+6, (y0+y1)/2). 값이 `true` 일 때만 찍는다 |
| `multiline` | `x0 y0 x1 y1` `size` `lineHeight` | 경위·사유 큰 상자 | 상자의 네 변 선 좌표. size 8.5, lineHeight 12.5 |

## 재료
`<scratchpad>/probe/<FORM_ID>/pN.json`(단어 bbox · 가로선 `hlines:[y,x0,x1]` · 세로선 `vlines:[x,y0,y1]` · 녹색 상자 · 괄호)과 `pN.jpg`(렌더).
다시 만들려면 `python scripts/probe_form.py forms/bundled/<FORM_ID>.pdf <출력폴더>`.
라벨 단어로 칸을 찾고, 그 라벨의 **오른쪽 첫 세로선 / 위·아래 가로선**으로 셀 경계를 정한다. 추정하지 말고 선 좌표를 쓴다.

## 무엇을 채우나
- **신청인(재해자·유족)이 쓰는 칸만.** 의사·사업주·공단 기재란(접수번호·소견서·진단서·확인란)은 넣지 않는다.
- 쪽은 **신청서 본문 쪽**만. 소견서·진단서·구비서류 안내 쪽은 뺀다.
- 체크는 양쪽을 다 칸으로 둔다(`xxx_yes`·`xxx_no`, 또는 구분 선택지마다 하나씩).
- 서명란·날인은 넣지 않는다(이름 글자만).

## 키 이름
영문 snake_case. 공통 키는 `F_YOYANG_APPLY.json` 과 **같은 이름**을 쓴다 — `name` `rrn` `address` `mobile` `phone` `accident_datetime` `workplace_no` `employer_name` `workplace_address` `apply_year` `apply_month` `apply_day` `applicant_name` `narrative`. 서식 고유 칸은 서식 안에서 뜻이 드러나게(예 `bank_name` `account_no` `claim_period_from`).

## 합성 값 파일 `test/samples/<FORM_ID>.json`
- 지도의 모든 키를 넣되, 체크의 반대편(선택하지 않은 쪽)은 `false`.
- **실명·실제 주민번호·실제 사업장·실제 계좌 금지.** 주민번호는 `9001011234567`(검증숫자 일부러 틀림), 계좌는 `000-00-000000`, 사업장관리번호는 `12345678901`.

## 끝나는 기준(전부 통과해야 끝)
```
npm run build
node scripts/fill_local.mjs forms/maps/<ID>.json forms/bundled/<ID>.pdf fonts/NanumGothic-Regular.ttf test/samples/<ID>.json <out.pdf>
python scripts/verify_fill.py <out.pdf> forms/maps/<ID>.json test/samples/<ID>.json <out.jpg> forms/bundled/<ID>.pdf   # 실패 0
npx vitest run test/maps.test.ts   # 해당 ID 전부 통과
```
그리고 `<out.jpg>` 를 **눈으로** 본다 — 글자가 선을 넘거나 옆 칸을 덮거나 상자 밖에 찍히면 좌표를 고치고 다시. 자동 검사 PASS 는 육안을 대신하지 못한다(261026 글리프 누락 사고).

## 하지 않을 것
- `src/`·`scripts/`·다른 서식의 지도·시험 파일을 고치지 않는다. 도구가 부족하면 보고만 한다.
- `forms/bundled/*.pdf` 를 바꾸지 않는다. `source_sha256` 은 `sha256sum forms/bundled/<ID>.pdf` 값.
