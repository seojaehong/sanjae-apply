## 1. 무엇인가 — 한 문단

급여 종류(요양·휴업·간병료이송비보조기·장해·유족·미지급·추가상병·재요양·본인부담치료비)와 재해 분기(업무상 사고·출퇴근·질병 × 제3자 유무 × 치료 종결 여부)를 받아 **필요한 서식·첨부·근거 조문·절차 안내·아직 답해야 할 질문**을 돌려주고, 요양급여신청서(별지 제2호, 2026.7.7 개정) PDF 를 **공단 정본 위에 값을 얹어** 돌려준다. 승인 가능성·확률은 계산하지도 출력하지도 않는다(코드 필터). 입력값은 서버에 저장하지 않는다.

```
입력 ──▶ 규칙 코어(S-01~S-13) ──▶ 패키지(서식/첨부/질문/근거/안내)
                 │
                 └──▶ PDF 오버레이(좌표 지도) ──▶ base64 PDF
출구 = MCP(운영 중) · CLI(규칙만) · 웹(미착수)
```

## 2. 지금 배포된 것

| 항목 | 값 |
|---|---|
| MCP URL | `https://sanjae-apply.vercel.app/api/mcp/mcp` (Streamable HTTP) |
| 인증 | `Authorization: Bearer <토큰>` · 토큰은 Vercel env `SANJAE_MCP_TOKENS`(쉼표로 여러 개) |
| 호스팅 | Vercel 프로젝트 `sanjae-apply`(팀 seojaehongs-projects) · GitHub `master` 푸시마다 자동 배포 |
| 도구 | `list_required_forms` · `get_form_catalog` · `fill_yoyang_apply` |
| 안내 페이지 | `https://sanjae-apply.vercel.app/` (noindex) |
| 토큰 보관 | 우리 쪽 `~/.config/sanjae-apply/mcp_token.txt`(600) · 채팅·문서에 적지 않는다 |

### 2-1. 우리가 다시 배포하는 법
```
git push origin master            # Vercel 이 자동 빌드·배포(약 20초)
# 또는 수동
vercel deploy --prod --yes --token $VERCEL_TOKEN --scope seojaehongs-projects
```
- 빌드 = `npm run build`(tsc → `dist/`) → Vercel 함수 `api/mcp/[transport].ts` 가 `dist/` 를 가져온다.
- `vercel.json` 의 `includeFiles` 가 `dist/**, forms/bundled/**, forms/maps/**, forms/catalog.json, fonts/**` 를 함수에 동봉한다. 여기 빠지면 운영에서 `ENOENT` 가 난다.
- `public/` 이 없으면 배포가 실패한다(outputDirectory).
- 배포별 주소(`sanjae-apply-xxxx-….vercel.app`)는 Vercel Authentication 으로 막혀 로그인 화면이 뜬다. **운영 알리아스 `sanjae-apply.vercel.app` 만 쓴다.**

### 2-2. 사무소에 토큰을 주는 법
1. 토큰 생성: `python -c "import secrets;print('sa_'+secrets.token_urlsafe(32))"`
2. Vercel env `SANJAE_MCP_TOKENS` 에 **쉼표로 이어 붙인다**(기존 값 유지). production 대상.
3. 재배포 없이 바로 유효하다(함수가 env 를 호출 때 읽는다).
4. 회수 = env 에서 그 토큰만 지운다. 사무소마다 토큰을 따로 주면 회수가 한 곳씩 된다.

### 2-3. 사무소가 직접 호스팅하려면(자체 서버)
- 요구: Node 24, `npm ci && npm run build`, env `SANJAE_MCP_TOKENS`, (법령 조회 쓰면) `LAW_GO_KR_OC`.
- Vercel 이면 이 레포를 포크해 그대로 올리면 된다. 다른 플랫폼은 `api/mcp/[transport].ts` 의 Web 표준 핸들러(`(req: Request) => Response`)를 그 플랫폼 함수에 감싸면 된다. Node 단독 서버 래퍼는 아직 없다(M4 과제).

## 3. 자기 AI 에서 호출하는 법(사무소 쪽)

| 클라이언트 | 방법 | 상태 |
|---|---|---|
| **Claude Code** | `claude mcp add --transport http --scope user sanjae-apply https://sanjae-apply.vercel.app/api/mcp/mcp --header "Authorization: Bearer <토큰>"` → `claude mcp list` 에 ✔ Connected | ✅ 실측(261026) |
| **Claude Desktop** | 설정 → 개발자 → MCP 서버 편집(`claude_desktop_config.json`)에 위 URL·헤더 | 미실측(같은 전송 규격) |
| **Cursor / Windsurf / VS Code Copilot** | MCP 설정에 `{"url": "...", "headers": {"Authorization": "Bearer <토큰>"}}` | 미실측 |
| **claude.ai 웹·앱 커넥터** | 「커스텀 커넥터 추가」는 **Bearer 헤더 입력 칸이 없고 OAuth 또는 무인증만** 받는다 | ❌ 지금은 불가 → OAuth(동적 클라이언트 등록) 붙이는 것이 M4 과제 |
| **ChatGPT 커넥터** | 같은 이유(OAuth/무인증) | ❌ 같은 과제 |
| **코드(파이썬·TS)** | 공식 MCP SDK 클라이언트 — 예시 `scripts/mcp_dryrun.mjs` | ✅ 실측 |

프롬프트 예(Claude Code 에서):
```
산재 요양급여 신청인데 출퇴근 중 사고이고 가해 차량이 있어. 필요한 서식·첨부 목록 뽑고, 아래 값으로 요양급여신청서 채워서 PDF 로 저장해줘.
```
→ 에이전트가 `list_required_forms` → (질문이 있으면 되묻고) → `fill_yoyang_apply` 를 부른다. PDF 는 base64 리소스로 오므로 클라이언트가 파일로 저장한다.

## 4. 다른 신청서도 다 되나

| 층 | 지금 | 나머지 |
|---|---|---|
| **필요 서식·첨부 판정** | 급여 9종 × 분기 전부(S-01~S-13) — 운영 드라이런 17케이스 PASS | 공단 규정(요양업무처리규정 등)과 대조는 안 했다. 블로그 실무 메모 + 법 조문 근거 |
| **PDF 채우기** | 요양급여신청서 1종(1쪽 47칸) | **12종 미작성.** 서식마다 좌표 지도 1개 — 격자선·녹색 상자 자동 추출 스크립트가 있어 1종당 1~2시간. 출퇴근용은 **합본 PDF**(신청서+소견서+발생신고서) 라 1쪽 배치를 다시 재야 한다 |
| **HWP 채우기** | 없음 | 공단 HWP 는 윈도우 한글 COM 으로만 채워진다(메모리 `reference_hwp_form_fill_com`). 서버에서는 못 돌리고 사무소 로컬 CLI 옵션으로 가능 |
| **소견서(의사 작성)** | 대상 아님 | 의사가 쓰는 칸이라 채우지 않는다. 안내문만 |
| **온라인 접수** | 없음 | 토탈서비스 보상 청구 메뉴 미실측. 중복 접수 위험이 있어 마지막(M5)으로 |

결론: **「무엇이 필요한가」는 전 급여에 답하고, 「서식을 채워 준다」는 1종.** 12종 추가는 같은 방법의 반복 작업이다.

## 6. 지켜야 할 경계

- **공인노무사법 §27**: 청구 대행·대리와 서류 작성·확인은 노무사 직무. 이 도구는 노무사(사무소)가 쓰는 보조 도구이고, 재해자 직접 서비스는 노무법인 명의로만(설계 §8 가정 1).
- **무저장**: 입력·PDF 를 서버에 남기지 않는다(루트 금지선 2 — 주민번호). 로그에 값이 찍히지 않게 `verboseLogs:false`. 사무소 쪽 클라이언트가 어디에 저장하는지는 사무소 책임.
- **승인 가능성·확률 출력 금지**: 코어 `assertNoOutcomeLanguage` 가 패키지를, MCP 가 응답을 한 번 더 거른다.
- **서식 정본**: 공단 서식자료실 파일만. 좌표 지도는 정본 sha256 에 묶여 있어 공단이 서식을 바꾸면 시험이 깨진다 — 그게 의도다.
- 이름·소개문에 「노무사」·「상담·진단·판정·대리·자문」을 쓰지 않는다(NOW.md).
