# 웹 편집기 설계 — 안내 페이지에서 바로 채우고 고치기 (261028 초안)

목표: 설치 없이 `sanjae-apply.vercel.app` 에서 서식을 고르고, 칸을 채우고, 결과를 보며 고친 뒤 PDF·한글 파일로 내려받는다. 결정 기록상 재해자 본인은 웹에서 직접 쓰는 경로다(G0 Q3, M4 ④).

## 핵심 원칙: 채우기를 브라우저 안에서 한다

서버 함수(`/api/mcp`)로 보내지 않는다. 입력값이 브라우저 밖으로 나가지 않으면 「입력값을 저장하지 않는다」를 말로 약속할 필요 없이 구조로 지킨다. 주민등록번호 같은 칸도 같은 원칙으로 다룬다.

이게 되는 근거(261028 코드 실측):

| 모듈 | node 의존 | 브라우저에서 |
|---|---|---|
| `src/core/*`, `src/rules/*` | 없음 | 이미 돈다 — `public/app/engine.js` (안내 페이지 확인표) |
| `src/fill/overlay.ts` `fillForm(pdfBytes, map, opt)` | 없음(pdf-lib·fontkit) | 바이트만 넘기면 된다 |
| `src/fill/hwpx.ts` `fillHwpx(hwpxBytes, map, opts)` | `node:crypto` 의 md5 한 곳(도장 그림 `hashkey`) | ✅ 순수 TS md5 로 바꿨다(261028, 같은 값). WebCrypto 에는 md5 가 없다 |
| `src/fill/registry.ts` | `fs`·`path` | ✅ `FormAssets` 타입(`src/fill/assets.ts`)에 node 구현 `nodeAssets`·브라우저 구현 `web/assets-fetch.ts` 둘(261028). 지도·PDF·글꼴은 `public/assets/` 정적 파일 |
| `src/stamp/seal.ts`·`raster.ts` | 없음(fontkit) | 그대로 돈다 |
| `src/stamp/png.ts` | `node:zlib` 의 `deflateSync` | ✅ `fflate` 의 `zlibSync` 로 바꿨다(261028) |

## 화면 모델

입력 모델은 이미 있다. `public/data/forms.json` 의 서식별 `slots[]`(key·kind·label·page·boxes·group)가 칸 목록이고, `npm run build:web` 이 지도에서 만든다. 손으로 쓴 폼 정의를 따로 두지 않는다.

- `kind` → 입력 요소: `text` 한 줄, `multiline` 여러 줄, `boxes` 자리 수가 정해진 칸(주민번호·우편번호), `check` 체크.
- 왼쪽 칸 목록 · 오른쪽 미리보기(채운 PDF 를 pdf.js 로 그림). 값을 바꾸면 그 칸이 있는 쪽만 다시 그린다.
- 확인표 결과의 「PDF·한글로 채울 수 있음」 링크가 편집기 진입점이 된다. 확인표에서 고른 급여로 필요한 서식이 미리 골라져 있다.
- 값 보관: 기본은 메모리뿐. 「이 기기에 임시 저장」을 켜면 `localStorage` 에 둔다. 서버 저장은 하지 않는다.
- 내려받기: PDF·hwpx 둘 다. 도장은 이름을 넣어 만들거나 PNG 를 올린다. 명의자 동의 문구를 같이 보인다.

## 단계

1. ✅ 로더 분리(261028) — `hwpx.ts` md5 → 순수 TS `src/fill/md5.ts`(node:crypto 와 같은 값, 시험), `png.ts` zlib → `fflate` `zlibSync`(풀어낸 스캔라인 동일), `seal.ts` 의 `Buffer` 제거. 칸 설명은 `src/fill/describe.ts` `describeForm` 하나로 합쳐 CLI `catalog`·MCP `get_form_catalog`·`forms.json` 이 같이 쓴다(전후 출력 14+14건 동일). `forms.json` 칸에 `boxes`(자리 수)와 `group`(체크 라벨 앞말)을 더했다. 자산 읽기는 `src/fill/assets.ts` `FormAssets` 타입 + `registry.ts` `nodeAssets` 까지 — fetch 구현은 자산을 정적 파일로 낼 때(2단계) 더한다. 끝 기준 = `npm run probe:web`(채우기·도장 모듈을 `--platform=browser` 로 묶음, `test:web` 안) + `lint:web`(DOM 타입만으로 타입 검사). ★ `group` 은 **하나만 고르는 묶음이라는 뜻이 아니다.** 「근로자유형」 8칸, 「미지급 보험급여 종류」 10칸 같은 묶음이 단일 선택인지 복수 선택인지는 서식마다 확인한 뒤 지도 json 에 `exclusive` 로 적는다(미정, 3단계 칸 입력 화면 전에 정한다).
2. ✅ 브라우저 PDF 채우기(261028) — `web/fill.ts` `fillPdf(formId, values, { stamp })` 를 `public/app/fill.js`(약 1.4MB, `--platform=browser`)로 묶고, 자산은 `web/assets-fetch.ts` `fetchAssets()`(FormAssets 의 fetch 구현)가 같은 출처 `public/assets/` 에서 받는다. `build:web` 이 서식 12종 지도·PDF 와 나눔고딕 전체 + `OFL.txt` 를 복사한다(gitignore). 게이트 `scripts/verify_web_fill.mjs`(`npm test` 안, Playwright): ① 안내 페이지 첫 로드에 채우기 자산 0건 ② 요양급여·휴업급여 견본 + 도장으로 브라우저 출력 = CLI 출력(쪽별 내용 스트림·그림 픽셀) ③ 채우는 동안 요청이 전부 같은 출처 정적 자산뿐. 자기시험 — 값을 바꾸면 ②, 외부 요청을 넣으면 ③ 이 실패한다. 버셀 빌드에는 Playwright 가 없어 이 게이트는 푸시 전 로컬과 운영(`URL=`)에서 돈다. 화면 연결은 3단계.
3. 칸 입력 화면 + 미리보기. 요양급여 74칸.
4. 한글 출력, 도장, 나머지 11종.
5. 보안 머리글 — 3단계 칸 입력 화면을 운영에 올리기 전에 CSP 를 Report-Only 로 `/` 에만 먼저 걸어 위반을 보고, Noto Serif KR·Pretendard 를 `public/` 에 자체 호스팅해 외부 글꼴 요청을 없앤다(261028 interrogate 「고려」 판정 — 지금은 Pretendard SRI 만).
6. 문체·금지어 필터를 화면 문구와 사용자 입력 경위문 양쪽에 건다.

## 정하지 않은 것

- (정함 261028) 정적 파일 용량 — 고른 서식의 지도·PDF 만 받고 글꼴은 전체를 한 번만 받는다. 첫 화면에는 아무것도 받지 않는다(게이트 ①).
- (정함 261028) 글꼴 라이선스 — 나눔고딕은 SIL OFL 1.1(근거 `fonts/OFL.txt`, NHN 2010). 상업 서비스에서 웹으로 내려주는 것(재배포)과 채운 PDF 에 넣는 것이 허용된다. 조건은 ①라이선스 전문을 글꼴과 함께 둔다(`public/assets/fonts/OFL.txt`, 바닥줄 링크) ②글꼴만 따로 팔지 않는다 ③서브셋·수정본은 「Nanum」 이름을 쓸 수 없다(Reserved Font Name). **용량을 줄이려고 서브셋하지 않는다** — 글리프가 사라지는 사고(261026)에 더해 라이선스 조건도 깨진다.
- 경위문 AI 작성 도움(M4 ④)을 넣으면 그 부분만은 입력이 밖으로 나간다. 넣는다면 따로 동의를 받는 화면이 필요하다.
- (정함 261028) 안내 페이지는 검색 색인을 허용한다.
