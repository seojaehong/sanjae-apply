# 한글(hwpx) 채우기 지도 작성법

PDF 좌표 지도(`forms/maps`)가 「어디에 그릴까」라면, 한글 지도(`forms/hwpx_maps`)는 「어느 표의 어느 칸에 넣을까」다.
공단 HWP 를 한글에서 hwpx 로 한 번 변환해 두고(`forms/hwpx/F_*.hwpx`, `scripts/hwp_to_hwpx.py --all`), 그 안의 표 칸 주소로 값을 넣는다.
채우기 자체는 한글 없이 돈다(`src/fill/hwpx.ts`, 순수 TS). 한글은 **검증**(실제로 열리고 그려지나)에만 쓴다.

## 0. 요양급여신청서에서 배운 것(261027)

- **표 번호 T 는 섹션 안 `<hp:tbl>` 등장 순서**이고 안쪽 표(칸 속 표)도 번호를 받는다. 요양급여는 T0 가 앞면 큰 표, T1~T36 이 주민번호·재해일시·관리번호 숫자 상자(1×1 표), **T37 이 「재해 발생 경위」 칸 안에 든 표**(경위 r0c0 + 경찰·소방·보험 질문 r1~r3)였다. 경위를 T0 r19 c1 에 넣으면 안 된다.
- **빈 칸의 run 은 자기닫힘(`<hp:run charPrIDRef="39"/>`)** 이다. 엔진이 펼쳐서 글자를 넣는다. 글자가 있는 문단에 `cell` 을 쓰면 그 글자가 **지워지고** 값만 남는다 — 라벨과 같은 문단이면 `after` 나 `group`(템플릿)을 쓴다.
- **자리표시자 색**: 경위 칸의 빈 문단 charPr 이 회색(#7F7F7F)이었다. 엔진이 검정 정체 사본을 header.xml 에 더해 쓴다(`CharPrFixer`). 검증기 ①이 값 run 의 색을 센다.
- **쪽수**는 공단 HWP 기준이다(요양급여 = 신청서 2 + 소견서 2 = 4쪽). PDF 지도의 쪽 수와 다를 수 있다. `expect_pages` 는 **렌더해 본 뒤** 넣는다.
- 라벨 뒤 빈 자리가 「채용일자:           년    월    일」처럼 한 run 에 들어 있으면 `group` 템플릿으로 **문단을 통째로** 다시 쓴다. 템플릿 글자는 원문의 라벨·괄호를 그대로 두고 `{칸}` 만 끼운다.

## 1. 도구

```bash
python scripts/probe_hwpx.py forms/hwpx/F_X.hwpx > /tmp/F_X_probe.txt     # 표·칸·문단 구조 전부
python scripts/probe_hwpx.py forms/hwpx/F_X.hwpx --grep 휴대전화           # 글자로 찾기
python scripts/probe_hwpx.py forms/hwpx/F_X.hwpx --cell T0:r26:c0          # 한 칸의 문단을 p0, p1, … 로 전부
sha256sum forms/hwpx/F_X.hwpx                                               # 지도 source_sha256
node scripts/fill_hwpx_local.mjs F_X test/samples/F_X.json /tmp/F_X.hwpx   # 채우기 (npm run build 뒤)
python scripts/verify_hwpx_fill.py /tmp/F_X.hwpx test/samples/F_X.json forms/hwpx_maps/F_X.json /tmp/F_X.jpg --no-render   # 한글 없이: zip 글자·체크 수·글자색
python scripts/verify_hwpx_fill.py /tmp/F_X.hwpx test/samples/F_X.json forms/hwpx_maps/F_X.json /tmp/F_X.jpg               # 한글 COM 렌더까지(윈도우, 다른 한글 창 없을 때만)
npx vitest run test/hwpx.test.ts
```

probe 출력 한 줄 = `T<표> r<행> c<열> (행병합×열병합) 「문단0 ¶ 문단1 ¶ … [안쪽표 N]」`. 라벨 칸 옆의 빈 칸 `「」` 이 값 칸이다.

## 2. 지도 JSON

```json
{
  "form_id": "F_X",
  "source_file": "F_X.hwpx",
  "source_sha256": "<forms/hwpx/F_X.hwpx 의 sha256>",
  "_about": "표 번호 안내(T0 = …, 안쪽 표 = …). 애매했던 칸.",
  "slots": { "<칸 이름 — forms/maps/F_X.json 과 똑같이>": <op> },
  "templates": { "<템플릿 이름>": { "t":0,"r":6,"c":13,"p":0, "text": "채용일자:  {hire_year}년  {hire_month}월  {hire_day}일" } }
}
```

| op | 언제 | 예 |
|---|---|---|
| `cell` | 빈 칸(또는 칸 안의 빈 문단)에 값. `p` 를 빼면 첫 빈 문단, 없으면 마지막 문단 | `{"kind":"cell","t":0,"r":16,"c":3}` · 라벨 아래 빈 줄이면 `"p":1` |
| `after` | 「휴대전화: 」처럼 라벨 run 끝에 값을 이어 붙임 | `{"kind":"after","t":0,"r":5,"c":13,"label":"휴대전화:"}` |
| `check` | 그 칸 글자 안 n번째 `[  ]`(→`[V]`) 또는 `□`(→`■`) | `{"kind":"check","t":0,"r":15,"c":1,"n":2}` |
| `digits` | 칸 안의 1×1 안쪽 표들에 한 글자씩(주민번호·관리번호) | `{"kind":"digits","t":0,"r":4,"c":12,"count":13}` · 두 묶음이 한 칸에 있으면 `"start"` |
| `cells` | 숫자 상자가 안쪽 표가 아니라 **이웃 칸**(c, c+1, …)인 서식 | `{"kind":"cells","t":2,"r":3,"c":4,"count":6}` |
| `group` | 여러 칸이 한 문단(년/월/일, 성명·연락처·관계)에 섞여 있을 때. 템플릿 문단을 통째로 다시 쓴다 | `{"kind":"group","template":"hire_date"}` |

규칙:
- **칸 이름 집합은 PDF 지도와 똑같아야 한다**(시험이 비교한다). PDF 지도에 없는 칸을 새로 만들지 않는다. PDF 지도 칸의 뜻은 그 JSON 의 `_about` 과 좌표(어느 라벨 옆인가)로 읽는다.
- 신청인이 쓰는 칸만. 의사·사업주·공단 칸은 넣지 않는다(PDF 지도와 같은 원칙).
- `group` 템플릿은 **원문 문단 글자를 그대로** 두고 `{칸}` 만 끼운다. 참조한 칸 중 하나라도 값이 있을 때만 문단을 바꾼다. 빠진 칸은 빈 글자가 된다.
- 체크의 `n` 은 **그 칸 안에서** 센다. 라벨 글자(「예 / 아니오」)를 보고 번호를 정한다.
- 값이 없는 칸은 건드리지 않는다(원문 그대로).

## 3. 검증 순서

1. `fill_hwpx_local.mjs` 가 `errors: []` — 주소가 틀리면 「칸 없음 T0 r99 c1」로 멈춘다.
2. `verify_hwpx_fill.py --no-render` **실패 0** — 글자 들어감·체크 수·mimetype·글자색.
3. `vitest run test/hwpx.test.ts` 통과 — 해시·칸 이름 집합·템플릿 참조.
4. (윈도우·한글) `verify_hwpx_fill.py` 렌더 — 한글이 열고 PDF 로 그리는지, 쪽수, 결합 JPEG 를 **눈으로** 본다. 칸이 늘어나 뒤 내용이 다음 쪽으로 밀리면 값을 줄이거나 문단 수를 본다. 이게 끝나야 `expect_pages` 를 넣는다.

## 4. 흔한 함정

- probe 가 `[probe] cellAddr/cellSpan 없음` 을 내면 표 안의 표 안의 표다 — 보고하고 그 칸은 비운다.
- 같은 라벨이 두 번 나오는 칸(「의료기관명: … 소재지: ¶ 의료기관명: … 소재지:」)에 `after` 를 쓰면 **첫 번째**에 붙는다. 두 번째가 필요하면 `group` 으로 문단 지정.
- `cell` 에 `p` 를 안 주면 「첫 빈 문단」인데, 빈 문단이 라벨 **위**에 있는 칸도 있다. probe `--cell` 로 문단 순서를 본다.
- 숫자 상자 수가 값 길이보다 적으면 엔진이 멈춘다(「글자 14 > 상자 13」). 합성 값을 줄이지 말고 상자 수를 다시 센다.
