🩹 산재 신청 도우미

급여 종류와 재해 상황을 말하면 필요한 서식·첨부·근거 조문을 알려 주고, 근로복지공단 정본 서식 12종을 PDF 또는 한글(hwpx)로 채워 줍니다. MCP 서버와 명령줄 도구입니다.

이 페이지는 운영 끝점 안내입니다. 끝점 /api/mcp/mcp (Streamable HTTP) 는 Authorization: Bearer … 토큰이 있어야 응답합니다. 설치 없이 내 PC 에서 쓰는 방법은 GitHub 안내서에 있습니다.

1. 무엇을 해 주나

하는 일설명
필요 서식 확인급여 9종(요양·휴업·장해·유족·간병료 등) × 사고/출퇴근/질병 × 제3자 유무 → 서식마다 REQUIRED / CONDITIONAL / NOT_APPLICABLE
첨부 점검이미 가진 것 PROVIDED, 없는 것 MISSING, 다른 서류로 갈음되는 것 SUBSTITUTABLE
근거 조문산재보험법·시행령·시행규칙 조문 번호와 제목(법제처 국가법령정보 Open API)
남은 질문아직 답이 없는 분기는 open_confirmations 로 되돌려 줍니다. 모르는 것을 지어내지 않습니다
서식 채우기공단 정본 PDF 위에 값을 얹거나(PDF), 공단 HWP 를 변환한 한글 문서에 값을 넣어(hwpx) 돌려줍니다. 신청인 칸만 채우고 의사·사업주·공단 칸은 비웁니다

2. 연결하는 법

  1. 운영자에게 토큰을 받습니다.
  2. Claude Code 에서 한 줄: 
    claude mcp add --transport http --scope user sanjae-apply https://sanjae-apply.vercel.app/api/mcp/mcp \
  --header "Authorization: Bearer <발급받은 토큰>"
  3. AI 에게 말합니다. 「출퇴근 중 교통사고인데 상대 운전자가 있어요. 요양급여 신청하려면 뭐가 필요해요?」 「이 값으로 요양급여신청서를 한글 파일로 채워 줘.」

Claude Desktop·Cursor 등은 같은 URL 과 헤더를 MCP 설정에 넣습니다. claude.ai 웹 커넥터는 토큰 헤더를 넣을 수 없어 아직 연결되지 않습니다.

3. 도구 4개

도구하는 일
list_required_forms급여·재해 분기 → 서식·첨부·조문·절차·남은 질문
get_form_catalog공단 정본 대장(파일명·개정일·sha256·게시글 URL), 채울 수 있는 서식(fillable PDF · fillable_hwpx 한글)과 칸 이름(slots)
fill_formform_id + 값 (+ format pdf·hwpx) → 채운 파일(base64)
fill_yoyang_applyv0.1 호환. fill_form(form_id="F_YOYANG_APPLY") 과 같음

5. 지키는 것

  • 승인 여부는 다루지 않습니다. 결과의 READY_TO_SUBMIT 은 「제출할 수 있는 상태」이지 승인이 아닙니다. 결과를 점치는 표현은 코드 필터가 출력 단계에서 막습니다.
  • 입력값을 저장하지 않습니다. 결과만 돌려주고 로그에 값이 남지 않습니다. 주민등록번호 같은 칸은 비워 두고 출력한 뒤 손으로 적어도 됩니다.
  • 공인노무사법 제27조에 따라 청구의 대행·대리와 서류의 작성·확인은 공인노무사의 직무입니다. 이 도구는 그 일을 돕는 도구이지 대신하지 않습니다. 출력물은 담당 노무사가 확인한 뒤 쓰십시오.
  • 온라인 접수(토탈서비스)는 범위 밖입니다. 채운 출력물을 만드는 것까지입니다.
