확인 결과

확인표를 고르면 여기에 결과가 나옵니다. 화면이 비어 있으면 자바스크립트가 꺼져 있는지 확인하세요.

같은 확인을 명령줄로 npx -y sanjae-apply check YOYANG --accident COMMUTE --third-party yes

이 확인은 브라우저 안에서만 돕니다. 고른 값은 어디에도 보내거나 저장하지 않습니다. 「제출할 수 있는 상태」가 나와도 승인 여부는 근로복지공단이 따로 정합니다.

내 도구에 연결하기

AI 도구에 붙이면 대화로 서식을 확인하고 채운 파일을 받습니다. Node.js 20 이상만 있으면 되고, 내 PC 에서 돌기 때문에 토큰이 필요 없습니다.

  1. 터미널에서 한 줄을 실행합니다. 
    claude mcp add --scope user sanjae-apply -- npx -y sanjae-apply mcp
  2. Claude Code 를 다시 열고 이렇게 물어봅니다.

    출퇴근 중 교통사고인데 상대 운전자가 있어요. 요양급여 신청하려면 뭐가 필요해요?

    요양급여신청서에 이 값으로 채워서 한글 파일로 줘.

  1. 설정 파일 claude_desktop_config.json 에 아래를 넣습니다. 윈도우 Microsoft Store 판은 %APPDATA%\Claude\ 에 있습니다. 
    {
  "mcpServers": {
    "sanjae-apply": { "command": "npx", "args": ["-y", "sanjae-apply", "mcp"] }
  }
}
  2. Claude Desktop 을 작업 표시줄 아이콘까지 종료한 뒤 다시 켭니다. 처음 도구를 부를 때 「허용」을 누릅니다.
    윈도우에서 npx 를 못 찾는다고 나오면 
    {
  "mcpServers": {
    "sanjae-apply": { "command": "cmd", "args": ["/c", "npx", "-y", "sanjae-apply", "mcp"] }
  }
}

Cursor·Windsurf 같은 다른 MCP 도구도 같은 command·args 를 넣으면 됩니다.

  1. 필요한 서식·첨부·근거 조문을 봅니다. 위 확인표의 「같은 확인을 명령줄로」와 같은 명령입니다. 
    npx -y sanjae-apply check YOYANG --accident COMMUTE --third-party yes
  2. 채울 서식의 칸 이름을 봅니다. 결과의 slots 가 값 파일의 열쇠입니다. 
    npx -y sanjae-apply catalog F_YOYANG_APPLY
  3. 값 파일로 채웁니다. 확장자를 .hwpx 로 주면 한글 파일이 나옵니다. --stamp 이름 을 붙이면 성명인을 찍습니다. 
    npx -y sanjae-apply fill F_YOYANG_APPLY values.json --out 신청서.pdf
npx -y sanjae-apply fill F_YOYANG_APPLY values.json --out 신청서.hwpx --stamp 홍길동

도장은 본인이거나 명의자가 동의한 이름만 넣으세요. 등록 인감을 대신하는 용도가 아닙니다.

운영자에게 토큰을 받은 경우에만 씁니다. 끝점 https://sanjae-apply.vercel.app/api/mcp/mcp 는 Authorization: Bearer 토큰이 없으면 응답하지 않습니다. 같은 도구 5개가 돌고, 입력은 저장하지 않지만 네트워크를 거칩니다.

claude mcp add --transport http --scope user sanjae-apply https://sanjae-apply.vercel.app/api/mcp/mcp \
  --header "Authorization: Bearer <발급받은 토큰>"

채울 수 있는 서식 12종

근로복지공단 서식자료실의 정본 파일 위에 값을 얹습니다. 신청인이 쓰는 칸만 채우고 의사·사업주·공단 칸은 비워 둡니다. 모두 836칸이고, 서식 이름을 누르면 채우는 칸 목록이 열립니다.

서식칸PDF한글도장 자리개정일

공단은 서식을 예고 없이 고칩니다. 칸 위치는 정본 파일의 해시에 묶여 있어, 서식이 바뀌면 시험이 먼저 깨지고 고친 판을 다시 냅니다.

이 페이지

확인표는 npm 패키지와 같은 규칙 코드를 브라우저용으로 묶은 것입니다. 배포 전에 모든 조합을 명령줄 결과와 대조합니다.

연결

내 PC 연결과 원격 연결 양쪽에서 도구 목록과 호출을 공식 SDK 로 시험합니다.

이 도구가 하지 않는 일

  • 승인 여부를 다루지 않습니다.서류가 갖춰졌는지만 봅니다. 산재 인정 여부는 근로복지공단이 정합니다.
  • 신청을 대신 내지 않습니다.채운 파일을 만드는 데까지입니다. 온라인 접수는 범위 밖입니다.
  • 서류 작성과 확인을 대신하지 않습니다.청구 대리와 서류 작성·확인은 공인노무사법 제27조에 따른 공인노무사의 직무입니다. 이 도구는 그 일을 돕습니다. 출력물은 담당 공인노무사가 확인한 뒤 쓰세요.
  • 입력값을 저장하지 않습니다.내 PC 에 설치하면 밖으로 아무것도 보내지 않습니다. 주민등록번호 칸은 비워 두고 출력한 뒤 손으로 적어도 됩니다.

이 페이지에서 바로 채우기

지금은 설치해서 써야 합니다. 다음 단계로 이 페이지 안에서 서식을 채우고 고쳐 내려받는 기능을 만들고 있습니다. 그때도 채우는 일은 브라우저 안에서만 하고, 값은 밖으로 나가지 않습니다.
